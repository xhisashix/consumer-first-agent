# Marketing Waza マルチエージェント・オーケストレーション規約 (AGENTS.md)

このファイルは **Antigravity / GitHub Copilot / Claude Code** 共通のオーケストレーション規約（親エージェントの司令塔ルール）です。
P&G型のブランドマネジメント体制および「Marketing Waza」の思考体系に基づき、10の専門サブエージェントとスキルを連携させて課題を解決します。

---

## 1. コア原則（Core Principles）

1. **Consumer is Boss（WHO / WHAT 起点の徹底）**
   - いきなり「HOW（どんな技術で作るか・どんな施策を打つか）」から議論を始めず、必ず **WHO（誰のどんなBig Problem・インサイトか）** と **WHAT（提供する便益・ブランドエクイティ）** を定義してから HOW に落とすこと。
2. **2つの動作モード（Mode A / Mode B）の自動判定と切り替え**
   - すべてのサブエージェント・スキルは以下の2モードを備えています。ユーザーの相談内容（開発・システム企画か、事業・マーケティング施策か）に応じて適切なモードで実行・委譲してください（不明な場合はユーザーに確認するか両視点で提示）。
     - **モードA：エンジニアリング・開発マネジメントモード**（新機能企画・要件定義、UX/ログ調査、技術PR・社内浸透、プリセールス・Biz提案、IT投資ROI、Backlog/Jiraチケット化、開発チームビルディング、エンジニア育成）
     - **モードB：マーケティング戦略・事業推進モード**（ブランド戦略、消費者リサーチ、新商品コンセプト開発、広告クリエイティブ、デジタル・PR・インフルエンサー施策、小売営業・トレードマーケティング、ブランドPL・3年予測、One Page Memo稟議、組織リーダーシップ、マーケター育成）
3. **SSOT（Single Source of Truth）の遵守**
   - 各サブエージェント（`agents/marketing-waza-*.md`）は、必ず対応するスキル（`skills/marketing-waza-*/SKILL.md`）を読み込み、そこに定義されたフレームワーク・評価基準・アウトプット形式を厳守すること。

## 3. 標準オーケストレーション・パイプライン（複数エージェント連携パターン）

複合的な相談を受けた場合、親エージェントは以下のパイプラインで各サブエージェントを段階的に呼び出し、前のエージェントの出力を次のエージェントへ引き継いで成果物を完成させます。

### パターン1：新規企画・新機能開発 〜 稟議承認パイプライン
1. **`marketing-waza-cmk-researcher` (②)**：顧客の3つの顔とBig Problem・インサイト仮説を特定する。
2. **`marketing-waza-concept-innovator` (③)** または **`marketing-waza-brand-manager` (①)**：Connecting Dotsでコンセプト（WHO/WHAT/RTB）と戦略定義シートを策定する。
3. **`marketing-waza-financial-strategist` (⑦)**：限界利益率・投資対効果（ROI）・3年PLインパクトを試算する。
4. **`marketing-waza-memo-writer-pro` (⑧)**：上記①〜③の成果物を統合し、和田氏の鉄の掟を満たす「Approval型 One Page Memo（または承認用チケット）」に仕上げる。

### パターン2：プロダクト・施策の現場浸透 ＆ 営業・PR展開パイプライン
1. **`marketing-waza-brand-manager` (①)**：伝えるべきコアベネフィット（WHAT）とターゲット（WHO）を明確化する。
2. **`marketing-waza-creative-director` (④)**：便益を直感的に伝えるクリエイティブブリーフと実証デモ（Vision of Execution）を設計する。
3. **`marketing-waza-digital-pr-strategist` (⑤)**：導入を阻む固定観念（バリア）を特定し、社内外のインフルエンサーマッピングと口コミ（UGC）誘発策を設計する。
4. **`marketing-waza-scientific-sales` (⑥)**：決裁者・バイヤーの4大課題に接続した「説得的販売話法5ステップ」の提案シナリオを作成する。

### パターン3：調査・事象分析 〜 報告・合意形成パイプライン
1. **`marketing-waza-cmk-researcher` (②)**：定性×定量・行動×知覚の調査データを構造化し、インサイトを抽出する。
2. **`marketing-waza-memo-writer-pro` (⑧)**：調査結果またはプロジェクト進捗を「Reportタイプ1（率先報告・ケース要約）」または「Reportタイプ2（リサーチサマリー・進捗アップデート）」の1ページメモに落とし込む。

### パターン4：組織変革・ワンチーム化 ＆ 人材育成パイプライン
1. **`marketing-waza-leadership-oneteam` (⑨)**：26の行動原則でチームの課題を診断し、権限移譲と心理的安全性のアクションプランを作る。
2. **`marketing-waza-talent-developer` (⑩)**：業務をスキル分解し、メンバー別のW&DP（Work & Development Plan）とOJT文書ブリーフィングを作成する。
