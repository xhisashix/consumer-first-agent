# Agent Orchestration & Routing Rules (AGENTS.md)

このファイルは **Antigravity / GitHub Copilot / Claude Code** 共通のオーケストレーション規約（親エージェントの司令塔ルール）です。

---

## 1. 基本方針（Core Principles）

- 専門的なサブタスクは、親エージェントが単独で抱え込まず、適切な **サブエージェント (`agents/`)** または **スキル (`skills/`)** を呼び出して処理すること。
- 各サブエージェントは、自身に割り当てられたロールと出力契約（Output Contract）を厳守し、詳細な手順は対応する `skills/<skill-name>/SKILL.md` を参照すること。

---

## 2. サブエージェント一覧とルーティング定義（Subagent Registry）

<!-- 後からサブエージェントを作成したら、以下の表に追記してください -->

| サブエージェント名 (`name`) | 定義ファイル | 主な役割・委譲タイミング | 参照スキル (`skills/`) |
| :--- | :--- | :--- | :--- |
| *(例) `researcher`* | `agents/researcher.md` | *市場調査・競合分析が必要なとき* | `skills/market-research/` |
| *(例) `copywriter`* | `agents/copywriter.md` | *訴求軸に基づくコピー・記事作成時* | `skills/copywriting/` |
| *(例) `reviewer`* | `agents/reviewer.md` | *成果物の品質チェック・校閲時* | `skills/quality-review/` |

---

## 3. オーケストレーション・ワークフロー（標準連携フロー）

<!-- 複数エージェントをどう連携させるかの全体フローをここに記述します -->

1. **要件整理・計画**: ユーザーの依頼を受け、必要なサブエージェントとスキルを選定する。
2. **調査・分析フェーズ**: 必要に応じてリサーチ系サブエージェントへ調査を委譲する。
3. **制作・実行フェーズ**: 調査結果をもとに制作系サブエージェントまたはスキルでアウトプットを生成する。
4. **検証・レビューフェーズ**: レビュー基準に基づき品質を検証してからユーザーへ提示する。
