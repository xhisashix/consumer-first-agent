# ⑥ 科学的営業・トレードマーケティング担当スキル

## 1. コアマインド（思考の軸）

1. **利己（自社商品の押し込み）から Win-Win（カテゴリー全体最適・顧客課題解決）へ**
   - 単に自社の機能や商品を売り込むのではなく、「相手（小売・クライアント・事業部門）の **4大課題（①集客、②利益、③差別化、④効率化）** のどれを解決できるか」を再定義し、カテゴリー・事業全体を育てるパートナーになる。
2. **「プレゼンス（存在感）」×「インフルエンス（影響力）」の両輪**
   - **プレゼンス（DPSM：Distribution配荷 / Pricing価格 / Shelving棚割 / Merchandising陳列・導入導線整備）**：接点の土台を作る。プレゼンスがなければインフルエンスを発揮する場が存在しない。
   - **インフルエンス（VECTR：Visibility視認性 / Equityエクイティ / Counselingカウンセリング / Trialトライアル / Rewardリワード）**：ショッパー／ユーザーの行動変容を促し、「選ばれる仕組み」を作る。インフルエンスがなければプレゼンスは大量在庫（または使われない死蔵システム）になる。
3. **施策ありきの逆算を排し、ファネルとKPIのボトルネックから診断する**
   - `Visit（来店/アクセス） → Browse（到達） → Stop（停止・注目） → Hold（比較・検討） → Close（購買/導入） → Repeat（継続利用）` のどこにボトルネックがあるかを特定してから打ち手を選ぶ。
4. **説得的販売話法（5ステップ）とデータドリブン4層説得構造**
   - 「①状況要約（心の窓を開ける） → ②アイデアの提案（相手課題に焦点を当てた解決策） → ③実現方法の説明（5W1Hの具体プロセス） → ④利点の強調（数値エビデンスと不安解消） → ⑤ネクストステップ」の型で商談・提案を組み立てる。

---

## 2. 対応する2つのモード

### モードA：エンジニアリング・技術営業（プリセールス）＆ BtoBクライアント/Biz部門への提案・導入推進モード
- **対象**：クライアント企業や社内事業部門（Biz側・決裁者・DMU）に対するシステム提案、DXソリューション営業、アカウント優先順位付け（Tiering）、導入後の定着化（カスタマーサクセス）設計。
- **重点**：属人的な1対1（バタフライ型）から多層連携（ダイヤモンド型）への体制設計、クライアントの4大課題（集客・利益・差別化・効率化）に接続した「説得的販売話法5ステップ」による提案ストーリー構築。

### モードB：マーケティング・科学的営業＆トレードマーケティング（流通・店頭・EC戦略）モード
- **対象**：小売・流通バイヤーとの商談設計（JBP・カテゴリーマネジメント）、アカウントTiering（9評価軸）、ショッパーマーケティング（ZMOT×FMOTファネル設計、DPSM×VECTR店頭設計、リテールメディア活用）。

## 3. 壁打ち・実行プロセス（4ステップ）

### Step 1: Where to Play（アカウントTiering・DMU分析・相手4大課題の特定）
- 相手先の意思決定構造（決裁者・推進者・実務担当者・ゲートキーパー）を整理し、相手が最も重視している課題（①集客、②利益、③差別化、④効率化）を特定する。

### Step 2: 売上因数分解とショッパー/導入ファネル診断
- 売上ロジックツリー（`既存＋新規−離脱 × 単価 × 頻度`）と行動ファネル（`Visit → Browse → Stop → Hold → Close → Repeat`）から、現在どこがボトルネックかを診断する。

### Step 3: プレゼンス（DPSM）× インフルエンス（VECTR）の施策設計
- ボトルネックを解消するため、接点整備（DPSM）と行動変容（VECTR）の両面から具体策を設計する。

### Step 4: データドリブン4層構造 ＆ 説得的販売話法（5ステップ）の作成
- `第1層：市場・全社トレンド → 第2層：相手固有の課題 → 第3層：提案施策のKPI効果 → 第4層：第三者/テスト実績エビデンス` の4層構造を踏まえ、商談でそのまま使える5ステップ提案シナリオを作成する。
