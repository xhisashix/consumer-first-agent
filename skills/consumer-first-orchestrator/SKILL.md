# Consumer-First マルチエージェント・オーケストレーションスキル

複数の `consumer-first-*` サブエージェント／スキルを連携させて一気通貫で課題を解決する際は、本スキルのパイプライン定義に従ってください。

## 1. 動作モードの判定
まずユーザーの相談テーマが以下のどちらに該当するかを判定します：
- **モードA（エンジニアリング・開発マネジメントモード）**：システム企画・新機能要件定義・UX/ログ調査・社内ツール浸透・技術営業・IT投資ROI・Backlog/Jiraチケット化・開発チーム運営・エンジニア育成
- **モードB（マーケティング戦略・事業推進モード）**：ブランド戦略・消費者リサーチ・新商品開発・広告制作・デジタル/PR/インフルエンサー施策・流通/小売営業・ブランドPL管理・稟議One Page Memo・組織リーダーシップ・マーケター育成

---

## 2. 標準連携パイプライン

### パイプライン1：新規企画・新機能開発 〜 稟議承認（One Page Memo）
1. `consumer-first-cmk-researcher`（②）：3つの顔（生活者・消費者・ショッパー）とBig Problem・インサイト仮説を特定
2. `consumer-first-concept-innovator`（③）または `consumer-first-brand-manager`（①）：Connecting Dotsでコンセプト（WHO/WHAT/RTB）と戦略定義シート（やめることを含む）を策定
3. `consumer-first-financial-strategist`（⑦）：限界利益率・投資対効果（ROI）・3年PL比較表（現状維持 vs 実行案の「差」）を試算
4. `consumer-first-memo-writer-pro`（⑧）：上記を統合し、One Page Memoの鉄の掟を満たす「Approval型 One Page Memo」を作成

### パイプライン2：プロダクト・施策の現場浸透 ＆ 営業・PR展開
1. `consumer-first-brand-manager`（①）：コアベネフィット（WHAT）とターゲット（WHO）を定義
2. `consumer-first-creative-director`（④）：便益を直感的に伝えるクリエイティブブリーフと実証デモ（Vision of Execution）を設計
3. `consumer-first-digital-pr-strategist`（⑤）：前進を妨げるバリアの特定、インフルエンサーマッピング、4要素PRメッセージとUGC誘発策を設計
4. `consumer-first-scientific-sales`（⑥）：決裁者・バイヤーの4大課題に接続した「説得的販売話法5ステップ」の提案シナリオを作成

### パイプライン3：調査・事象分析 〜 報告・合意形成
1. `consumer-first-cmk-researcher`（②）：定性×定量・行動×知覚の調査設計またはデータからのインサイト抽出
2. `consumer-first-memo-writer-pro`（⑧）：「Reportタイプ1（率先報告・ケース要約）」または「Reportタイプ2（リサーチサマリー・プロジェクト進捗報告）」の1ページメモを作成

### パイプライン4：組織変革・ワンチーム化 ＆ 人材育成
1. `consumer-first-leadership-oneteam`（⑨）：26の行動原則でチーム課題を診断し、ジョハリの窓・権限移譲・ストレッチ目標の行動計画を作成
2. `consumer-first-talent-developer`（⑩）：業務をスキル分解（KSA）し、OJT文書ブリーフィングと年間W&DP（70:20:10計画）を作成
